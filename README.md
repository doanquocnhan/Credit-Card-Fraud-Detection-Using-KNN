# Credit Card Fraud Detection Using KNN

A machine learning experiment that uses the **K-Nearest Neighbors (KNN)** algorithm to detect fraudulent credit card transactions.

## Overview
Fraudulent transactions are rare compared with legitimate ones, which makes fraud detection a classic imbalanced-classification problem. This project explores how a simple, interpretable algorithm like KNN performs on transaction data, following the full workflow: data preparation, model training, and evaluation.

## Repository contents
- `Credit_Card_Fraud_Detection_USing_KNN.ipynb` - the main notebook with the KNN fraud-detection workflow
- `DoAn.ipynb` - the project notebook
- `BaoCao_4Tuandau.pptx` - progress report slides (in Vietnamese)

## Tech stack
- Python, Jupyter Notebook
- scikit-learn, pandas, NumPy, matplotlib

## How to run
1. Clone this repository and open the notebook in Jupyter or Google Colab.
2. Install the libraries listed above if they are not already available.
3. Place the transaction dataset where the notebook expects it, then run the cells in order.

## Note
This is an academic/coursework project created for learning purposes, not a production fraud-detection system.
